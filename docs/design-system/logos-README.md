Logos oficiais do Missão: a onça-pintada com o nome "missão" em Helvetica, e a bandeira de três faixas. Use sempre o SVG; o PNG fica só para onde SVG não é aceito.

- `missao-logo-vertical-texto-preto.svg` / `.png`: assinatura vertical, nome em `preto`, onça sobre quadro preto, fundo do nome transparente. Para fundos claros (`surface` claro, `branco`).
- `missao-logo-vertical-fundo-preto.svg` / `.png`: a mesma assinatura sobre fundo `preto` com respiro, nome em `branco`. Para peças escuras, capas e redes.
- `missao-bandeira.svg` / `.png`: bandeira com faixas `preto`, `branco` e `amarelo` e "missão" em preto. Para capas, perfis e materiais institucionais.

Cores dentro dos arquivos: amarelo `#FDBD27`/`#FDBE22`/`#FCBE26` (todos são o `amarelo`), cinza `#656364`/`#636363` (o `cinza-onca`). Como SVG entra por `<img>`, a cor não muda com o tema: escolha o arquivo pelo fundo.

Nunca redesenhe, recolora ou distorça. Tamanho mínimo da assinatura vertical: 48px de altura em tela. Ainda falta o nome sozinho na horizontal, se existir.
